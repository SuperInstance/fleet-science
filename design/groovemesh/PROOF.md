## §1. Definitions

**Definition 1.1 (Pitch Class).** A pitch class is an element of ℤ₁₂ = {0,1,...,11}.

**Definition 1.2 (Triad Space T₂₄).** Let
```
  T₂₄ = ℤ₁₂ × {+, −}
```
where `+` denotes major quality and `−` denotes minor quality. Elements are written
`r⁺` (major triad with root r) and `r⁻` (minor triad with root r). |T₂₄| = 24.

**Definition 1.3 (Pitch-class content).** The PC-set of a triad t = (r, q) is:
```
  pcs(r, +) = { r,  r+4,  r+7 }   (root, major third, perfect fifth, all mod 12)
  pcs(r, −) = { r,  r+3,  r+7 }   (root, minor third, perfect fifth, all mod 12)
```

**Definition 1.4 (PLR Operations — Canonical).** Define three maps on T₂₄:

```
  P : T₂₄ → T₂₄         (Parallel — same root, flip quality)
      P(r, +) = (r, −)
      P(r, −) = (r, +)

  L : T₂₄ → T₂₄         (Leading-tone exchange)
      L(r, +) = (r+4  mod 12, −)
      L(r, −) = (r−4  mod 12, +)     ← canonical; see Note 1.5

  R : T₂₄ → T₂₄         (Relative)
      R(r, +) = (r+9  mod 12, −)
      R(r, −) = (r+3  mod 12, +)
```

**Note 1.5 (Implementation Discrepancy).** The current implementation in
`flux-algebra-rs/src/groups.rs:52` uses `r−1` instead of `r−4` for `L` on minor
triads. This causes L to have order 8 rather than 2, producing a group of order 96
rather than 24. The canonical definition above uses `r−4` to make L an involution
(L² = id), matching standard neo-Riemannian theory (Cohn 1997, Hook 2002).
**The GrooveMesh implementation MUST use `r−4`.** The safety guarantee is preserved
under either definition, but the canonical group is D₁₂ (order 24), which is smaller,
faster to enumerate, and maps directly to the classical Tonnetz.

## §2. PLR Forms a Group

**Theorem 2.1.** Let G = ⟨P, L, R⟩ be the group generated by P, L, R under function
composition acting on T₂₄. With the canonical Definition 1.4, G is a group isomorphic
to the dihedral group D₁₂ of order 24.

**Proof.**

We verify the four group axioms.

### 2.1 Closure

Each generator maps T₂₄ → T₂₄:
- P swaps quality at the same root; root ∈ ℤ₁₂ ✓
- L shifts root by ±4 in ℤ₁₂ and flips quality; result has root ∈ ℤ₁₂ ✓  
- R shifts root by +9 or +3 in ℤ₁₂ and flips quality; result has root ∈ ℤ₁₂ ✓

Since composition of maps T₂₄ → T₂₄ is closed, all products of generators lie in
the set of bijections T₂₄ → T₂₄, so G ≤ Sym(T₂₄). Closure holds. □

### 2.2 Associativity

Function composition is associative. □

### 2.3 Identity

The identity element `e = id` acts as `id(t) = t` for all t ∈ T₂₄.

Show e ∈ G via involution products:

**P² = id:**
```
  P(P(r, +)) = P(r, −) = (r, +)  ✓
  P(P(r, −)) = P(r, +) = (r, −)  ✓
```

**L² = id (canonical definition):**
```
  L(L(r, +)) = L((r+4) mod 12, −)
             = ((r+4−4) mod 12, +)
             = (r, +)              ✓

  L(L(r, −)) = L((r−4) mod 12, +)
             = ((r−4+4) mod 12, −)
             = (r, −)              ✓
```

**R² = id:**
```
  R(R(r, +)) = R((r+9) mod 12, −)
             = ((r+9+3) mod 12, +)
             = ((r+12) mod 12, +)
             = (r, +)              ✓

  R(R(r, −)) = R((r+3) mod 12, +)
             = ((r+3+9) mod 12, −)
             = ((r+12) mod 12, −)
             = (r, −)              ✓
```

So P, L, R are all involutions; each is its own inverse; id = P² = L² = R² ∈ G. □

### 2.4 Inverses

Since P, L, R are involutions: P⁻¹ = P, L⁻¹ = L, R⁻¹ = R.
For any product g = g₁g₂...gₙ (each gᵢ ∈ {P,L,R}):
  g⁻¹ = gₙgₙ₋₁...g₁
and since each gᵢ⁻¹ = gᵢ, this is gₙ...g₁ ∈ G. □

### 2.5 Order and Isomorphism

The orbit of 0⁺ under G:

```
  RL: 0⁺ → R → 9⁻ → L → 5⁺ → R → 2⁻ → L → 10⁺ → R → 7⁻ → L → 3⁺
         → R → 0⁻ → L → 8⁺ → R → 5⁻ → L → 1⁺ → R → 10⁻ → L → 6⁺
         → R → 3⁻ → L → 11⁺ → R → 8⁻ → L → 4⁺ → R → 1⁻ → L → 9⁺
         → R → 6⁻ → L → 2⁺ → R → 11⁻ → L → 7⁺ → R → 4⁻ → L → 0⁺
```

RL has order 12. Since P is an involution that conjugates the RL-orbit (P maps the
orbit to itself non-trivially), G = ⟨RL, P⟩ with (RL)¹² = P² = id and
P(RL)P = (RL)⁻¹ (verified by direct computation). This is the presentation of D₁₂.

∴ G ≅ D₁₂, |G| = 24. □

## §3. Embedding in a Lie Group

**Theorem 3.1.** The PLR group G ≅ D₁₂ embeds as a discrete subgroup of the
Lie group GL(24, ℝ).

**Proof.**

Label the elements of T₂₄ as t₁, t₂, ..., t₂₄ in some fixed order.

Each g ∈ G induces a permutation σ_g ∈ Sym(24). Represent σ_g as a permutation
matrix M_g ∈ GL(24, ℝ) via:
```
  (M_g)ᵢⱼ = 1  if g(tⱼ) = tᵢ
           = 0  otherwise
```

The map φ: G → GL(24, ℝ), g ↦ M_g is a group homomorphism:
- φ(id) = I₂₄
- φ(gh) = M_{gh} = M_g M_h  (permutation matrices multiply correctly)
- φ is injective: if M_g = M_h then g = h (since the permutation uniquely determines g)

GL(24, ℝ) is a Lie group (smooth manifold with smooth group operations).
G = φ(G) is a finite subgroup of GL(24, ℝ), hence a closed discrete subgroup,
hence a 0-dimensional Lie subgroup. □

**Remark 3.2 (Richer Embedding via Tonnetz).** G also embeds in the Lie group
Isom(ℝ²), the isometry group of the Euclidean plane, as follows.

The Tonnetz is a 2D lattice in ℝ² with basis vectors e₁ = (1,0) (major-third axis)
and e₂ = (1/2, √3/2) (perfect-fifth axis). Each triad t_i occupies a fixed lattice
point in this fundamental domain (quotiented by the 12-fold pitch-class periodicity,
it lives on a torus T²). The PLR operations act as reflections across specific axes:

```
  P: reflection across the horizontal axis through each major triad
  L: reflection across axes inclined at 60°
  R: reflection across axes inclined at 120°
```

These are all elements of O(2) ⋊ ℤ² (the symmetry group of the triangular lattice,
a.k.a. the wallpaper group p3m1), which is a closed subgroup of Isom(ℝ²).

The "SLIDE" intuition: a continuous path between two triads in ℝ² is a smooth
curve. The PLR group tiles ℝ² with Voronoi cells (one per triad). The path
crosses cell boundaries at the moments of harmonic change. Each boundary is a
PLR reflection axis: crossing it fires the corresponding PLR operation. The
group structure guarantees you always land inside a valid cell. □

## §4. O(1) Nearest-Legal-Neighbor

**Theorem 4.1.** Given any set of at most 12 pitch classes P ⊆ ℤ₁₂, the nearest
triad under the voice-leading metric is computable in O(1).

**Definition 4.2 (Voice-Leading Metric).** For a multiset of pitch classes P and
triad t, define:
```
  d(P, t) = Σ_{p ∈ P} min_{c ∈ pcs(t)} |p − c|₁₂
```
where |x|₁₂ = min(x mod 12, 12 − x mod 12) is the chromatic distance mod 12.

**Theorem 4.1 (Proof).**

**Step 1: Bitmask encoding.**
Any subset of ℤ₁₂ is representable as a 12-bit integer b ∈ {0, ..., 4095}:
bit i is set iff pitch class i is present. There are at most 2¹² = 4096 such masks.

**Step 2: Precomputation.**
At initialization (O(4096 × 24) = O(1) amortized), build array:
```rust
  NEAREST: [u8; 4096]   // index = pc_bitmask, value = triad index in T₂₄
```
For each mask m ∈ [0, 4096):
  - Compute pcs(m) = {i : bit i of m is set}
  - For each t ∈ T₂₄, compute d(pcs(m), t)
  - NEAREST[m] = argmin_t d(pcs(m), t)

This is computed once. The array fits in 4 KB (4096 × 1 byte), within L1 cache.

**Step 3: Lookup.**
Given input pitch classes P:
  1. Compute bitmask: m = Σ_{p ∈ P} 2^p  (one OR per note, O(|P|) ≤ O(12) = O(1))
  2. Return TRIAD_TABLE[NEAREST[m]]       (array lookup, O(1))

Total: O(1) amortized after O(1) initialization (constant-bound problem size). □

**Corollary 4.3 (No Wrong Note).** In a running GrooveMesh session with current
chord state t ∈ T₂₄, any note n played by any client is projected to a pitch class
in pcs(t) via the mapping:
```
  project(n, t) = argmin_{c ∈ pcs(t)} |n mod 12 − c|₁₂
```
This is a lookup over a 3-element set, O(1). The result is always in pcs(t) ⊆ T₂₄.
Therefore, the system always emits notes belonging to the current valid triad. □

**Corollary 4.4 (PLR Path Existence).** For any two triads s, t ∈ T₂₄, there exists
a path s = g₀, g₁, ..., gₖ = t where each consecutive pair is related by a PLR
operation, and k ≤ 6.

*Proof.* The Tonnetz graph (T₂₄, PLR edges) is connected: G acts transitively on T₂₄
(the orbit of any triad is all 24 triads, since G ≅ D₁₂ acts regularly on T₂₄).
The diameter of the Tonnetz graph is at most 6 (computational verification: BFS from
any node reaches all 24 nodes within 6 hops). □

## §5. The "No Wrong Note" Invariant (Formal Statement)

**Invariant 5.1.** Let `σ: ℕ → T₂₄` be the session's chord-state sequence
(σ(0) ∈ T₂₄ is the initial chord; σ(k+1) = op(σ(k)) for some op ∈ {P, L, R}).

Then ∀k ∈ ℕ: σ(k) ∈ T₂₄.

*Proof.* By induction:
- Base: σ(0) ∈ T₂₄ by initialization.
- Step: Assume σ(k) ∈ T₂₄. By Theorem 2.1 (closure), op(σ(k)) ∈ T₂₄. □

**Invariant 5.2.** Every note emitted by GrooveMesh is in pcs(σ(k)) for some
k ∈ ℕ, and therefore is a pitch class of a standard major or minor triad. □
